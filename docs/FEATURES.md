# KoreAgent Next 功能说明

本文按当前 Electron 页面、Python JSON-RPC 方法和本地数据流说明功能。页面名称以桌面端实际导航为准；接口存在不代表第三方账号已经连接或权限已经授予。

## 1. 页面和导航

| 导航 | 页面 | 作用 |
| --- | --- | --- |
| 工作台 | 今天 | 今日摘要、行动、目标、通知、外部信息和网页监控更新 |
| 对话 | 对话 | 向 Agent 提问、让 Agent 调用工具或先生成执行计划 |
| 信息中心 | 收件箱 | 邮箱、日历、飞书任务和文档的统一收件流 |
| 信息中心 | 统一搜索 | 跨会话、连接器、记忆、任务和工作区文件搜索 |
| 信息中心 | 长期记忆 | 记忆审核、搜索、维护、版本和导出 |
| 研究中心 | 研究 | 研究会话、报告、来源、引用覆盖率和版本 |
| 研究中心 | 主动执行 | 主动建议、触发器和需要用户批准的主动任务 |
| 执行中心 | 运行记录 | 运行状态、时间线、Token、工具调用、错误和恢复 |
| 执行中心 | 任务与计划 | 待确认、进行中、已阻塞、已完成和已取消任务 |
| 执行中心 | 自动化 | 一次性、间隔或 Cron 形式的 Agent 任务 |
| 执行中心 | 审批 | 工具权限和外部写入动作的审批队列 |
| 执行中心 | 外部操作 | 邮件、日历、飞书任务和文档写入的结果、核实和恢复 |
| 执行中心 | 交付物 | Agent 生成的本地文件或 URL |
| 设置 | 设置 | 模型、预算、工作区、隐私、通知、备份和应用初始化 |
| 设置 | 连接器健康 | 连接状态、同步、Token、错误中心、重试和重新授权 |

页面都有加载中、错误、空数据和重试状态。Host 断开时，顶部会显示离线提示；重新连接后页面会重新读取对应数据。

## 2. 工作台

工作台由后端先整理结构化上下文，再由模型生成简短的今日摘要。结构化数据包括今日行动、后续行动、活跃目标、今天仍未读的通知、重要且有建议的外部信息、今天即将开始的日历事件，以及连接器异常或授权提醒。摘要下方保留统计数字，点击“查看详情”可以查看用于生成摘要的只读上下文。

“新建行动”使用独立表单填写主题、内容和可选截止时间。截止时间按个人时区解释：今天的行动进入“今日行动”，未来日期或未定时间进入“后续行动”。超过截止时间但未完成的行动会标记为已逾期；每条行动都可以直接完成。

目标可以快速创建，也可以让 Agent 规划。规划预览会分别展示目标、阶段性行动、任务计划和自动化提醒，用户可以取消不需要的部分、继续讨论，确认后才保存。目标详情列出关联行动、任务和自动化提醒。

外部信息来自连接器同步后的邮件、日历、飞书任务和云文档。系统会根据重要性、建议行动、是否需要回复或确认进行筛选；普通订阅、营销邮件、垃圾邮件和没有明确行动的信息通常只留在收件箱。详情包含原始内容、分析依据和建议。建议可以逐条勾选；本地行动可直接创建，回复邮件、创建日历、创建飞书任务或写入文档会先生成审批项。用户也可以修改、忽略或与 Agent 讨论。

网页监控更新单独展示，不依赖行动建议才显示。每条更新可以查看新增标题、链接、摘要、变化摘要、重要性、来源可信度和前后正文对比，也可以标记已读、收藏、忽略、打开来源或与 Agent 讨论。

## 3. 对话和计划

普通模式适合问答、文件读取、搜索、总结和连续工具调用。消息、模型思考、工具调用、工具结果和最终回答属于同一次运行。工具调用默认折叠，点击后查看完整内容。

计划模式先创建待确认计划，不会立即执行。计划卡片展示有序步骤、说明和成功条件；用户可以退回或接受。接受后任务进入执行中心，步骤状态和运行记录同步更新。被阻塞任务可以重试，运行中断后可以从检查点恢复。

工作台目标规划使用 `goal.plan.preview` 生成只读预览，`goal.plan.discuss` 更新预览，`goal.plan.apply` 在确认后创建目标、行动、任务和自动化。它不会直接创建邮件、日历、飞书任务或云文档。

## 4. 收件箱和统一搜索

收件箱提供全部、邮件、日历、任务和文档筛选；日历还可切换全部、未来和已过期。点击详情会标记邮件已读，并展示正文、状态、附件和关联信息。附件通过短期下载令牌下载。收件箱的完成状态是本地处理状态，不会删除远程邮件，也不会改变远程日历或飞书任务；邮件必须先已读才能本地完成。

统一搜索列表只返回标题、摘要和元数据。点击“查看详情”才读取会话上下文、完整连接器项目、完整记忆、个人对象或工作区文件。敏感 Token 和本地绝对路径会过滤，详情可以打开原模块。

## 5. 研究、监控和主动执行

研究会话来自对话中的网页研究请求，也可以由监控主题的后台运行生成。研究详情包括回答、结论依据、不确定性、来源、引用覆盖率、相关本地上下文和历史版本，并支持导出 Markdown。

监控主题支持自然语言时间、主题、来源 URL 和域名限制。没有 URL 时先搜索候选网站，确认后才创建。监控支持手动运行、重试、重新授权、恢复和删除；更新支持查看、忽略、收藏、打开来源和讨论。

主动执行根据新连接器信息、研究监控更新、外部操作部分成功或结果未知、日历或飞书任务临近截止等事件产生建议。触发器可以开启或关闭，建议和执行作业分开保存，用户可以接受、拒绝、暂停、恢复并查看审计。

## 6. 执行中心

运行记录保存用户输入、模型调用、工具调用、工具结果、阶段状态、Token 用量、上下文压缩、错误、交付物和恢复信息。可查看、取消、删除和恢复。运行预算可选择无限制或自定义，单次运行仍受工具步数安全护栏约束。

任务与计划按待确认、进行中、已阻塞、已完成和已取消切换；步骤可以逐项完成，长期目标任务保留目标和阶段关联。自动化支持一次性、间隔和 Cron 调度，可暂停、恢复或取消。审批处理工具权限和外部写入。外部操作记录脱敏预览、状态、远端 ID、核实结果和 Saga 步骤，支持结果未知核实、失败后继续、重试和已知对象的补偿。交付物页列出 Agent 创建的本地文件或 URL。

## 7. 长期记忆和设置

长期记忆按待确认、活跃和归档切换。详情显示完整内容、来源、置信度、置信度来源、证据、冲突和版本。确认、拒绝、删除、冲突解决和回滚都会保留状态；维护和检查由 Host 定期执行，也可点击“立即检查”。

设置可以配置主模型、反思、维护、摘要和技能学习角色，各模型上下文窗口、运行预算、个人时区、隐私/记忆审核、通知、工作区、技能和数据初始化。完整 RPC 注册表可通过 Host `/health` 返回的 `rpc_methods` 查看。
