## 第一批：运行恢复、工作区与审批生命周期

已核对 RUN4-002、RUN4-004、RUN4-005、SAG2-005、SAG3-012。其结果要求有效，不需要降低要求。原 RUN4-005 只证明取消后的旧卡仍可批准，没有证明实际发送邮件。

实现：

- 同一源运行只允许认领一次恢复；子运行、工作区、检查点和认领记录在同一事务提交。重复请求返回已有子运行 ID 的明确错误。后续失败可恢复子运行。
- 每次创建运行记录原工作区；切换目录检查活动及尚未启动的运行。恢复目录不匹配时要求回原目录；未记录工作区的历史运行明确拒绝安全性无法确认的恢复。
- 取消运行原子失效待审批卡。审批决定、权限规则及待执行外部操作状态统一提交；外部派发再次校验运行状态。已派发请求中断后保留结果未知，不能伪称撤销。
- 补偿成功或核实后清除旧请求错误；按步骤状态给出恢复指引。补偿目标约束保留，原失败审计保留。

验证：14 项隔离生命周期测试通过；TypeScript 检查与 Ruff 通过。SAG2-005 / SAG3-012 已通过真实前端操作完成确定失败、未知已执行、未知未执行、篡改目标与邮件不支持补偿分支，保存界面、RPC、替身远端及审计证据。三条运行恢复用例的额外桌面验收待最终汇总，不将单元验证冒充完整用例通过。

## 第二批：工作台与来源一致性

已核对 WB4-004、WB4-011、WB4-012、FLOW4-003、FLOW4-012、INFO4-017，原预期有效。EXT-004 原合同只检验审批预览，原通过成绩不变；新验证补充“适配器不支持标签时，在审批前明确拒绝，不能静默丢弃标签”，以及无标签的正常创建路径。完整执行合同需区分支持参数与不支持参数，不能用预览通过推断标签已被远端保存。

实现：

- 行动与任务步骤在同一事务内按 plan_id / stage_id 双向同步；同名不同阶段不合并，多行动阶段需全部完成。重新打开可撤销完成状态，同名无关对象保持原状。
- 提醒保留带类型的实体引用及逐项内容；完成时仅消解对应事项并重算合并提醒。逾期扫描包含未完成逾期行动，避免已完成旧扫描结果再次生成催办。
- 飞书任务远端完成状态参与同步比较，覆盖本地旧值；分析指纹包含完成状态、日期及收件目标等语义字段。完成任务不再保留完成它的待办，旧版本异步分析不能覆盖新版本。
- 接受来源建议、创建审批、批准及外部派发时重新验证同一来源的存在和版本。只读标记变化不会使审批失效；来源删除或收件目标变化会失效。
- 不支持的飞书任务标签在创建审批前说明限制；保持合法无标签任务创建。

验证：17 项工作台／来源集成测试与第一批 14 项生命周期测试通过（31 项）。真实飞书完成同步及受影响 UI、模型端到端验收仍需在最后一轮补齐，当前不将隔离替身成绩称为真实连接器验收。
