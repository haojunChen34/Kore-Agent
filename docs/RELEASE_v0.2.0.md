# v0.2.0：运行恢复、审批与跨模块状态一致性改进

版本说明日期：2026-11-26。继续沿用Kore-Agent仓库及历史，本版本提供源码运行方式。

本版本集中改进任务执行的可靠性，修复运行恢复、审批生命周期、工作台联动和外部服务同步中的状态一致性问题。

- **运行恢复与审批**：防止同一检查点重复执行，强化工作区绑定，修正旧审批失效与拒绝信息传递；外部操作成功后，即使后续运行失败，也明确展示已经发生的操作。
- **工作台与外部信息**：改进行动、计划阶段和提醒联动；修复远端任务完成后的本地同步，以及旧分析结果覆盖新来源的问题。
- **详情与来源访问**：修复详情切换竞态，完善行动来源入口、附件下载和跨类型信息数量统计。
- **工具与执行核验**：改进MCP工具发现、分页和参数校验，加强只读约束、交付检查、引用依据及网页正文提取。
- **恢复界面**：已恢复的旧记录显示“查看后续运行”；操作错误仅归属于对应记录，迟到响应不会影响其他记录。
- **开发与测试**：公开6个后端回归测试文件及恢复界面交互测试；测试运行方式统一放在[贡献指南](../CONTRIBUTING.md)。启动脚本补充检查新增的jsonschema依赖，避免复用旧环境时漏装。

## 验证

- 后端隔离回归64/64通过；浏览器交互检查10项通过。
- 类型检查、生产构建及产品Ruff检查通过；生产构建存在已有的大包体提示。
- 四套综合测评分阶段验收共322条：316通过、6未通过。结果汇总多个修复阶段，最新恢复界面修复另做定向回归。

## 已知限制

仍包括飞书任务标签支持，以及部分场景中的责任主体判断、额外工具尝试、恢复建议、时区表达和冲突确认提示。详细结果、分母和验证范围见[测评结果](../evals/RESULTS_v0.2.0.md)。

## 升级

保留自己的配置和本地数据，停止旧版本正在执行的任务后再升级并重启Host和桌面端。依赖变更后按[README](../README.md)安装；不要用他人的数据库或配置覆盖现有数据。恢复检查点继续绑定原工作区，重复恢复同一检查点仍由后端拒绝，界面会引导查看已有后续运行。
